# Endless Driving

Rahatlatıcı, sonsuz manzara sürüşü — Android oyunu (tamamen çevrimdışı, ≈486 MB).

## İndir (tek dosya)

**[Endless Driving'i indir (ZIP, ≈486 MB)](https://github.com/selenmustafa58-a11y/endless-driving/archive/refs/heads/main.zip)**

## Kurulum (telefonda)

1. Yukarıdaki linke dokun; `endless-driving-main.zip` iner.
2. Ücretsiz **ZArchiver** uygulamasıyla bu ZIP'i aç ve **Buraya çıkar** de.
3. Çıkan klasörde **`EndlessDriving.zip.001`** dosyasına dokun → **Buraya çıkar**.
   (ZArchiver 6 parçayı kendisi birleştirir.)
4. Oluşan **`Endless Driving.apk`** dosyasına dokun → **Yükle**.
   Telefon "bilinmeyen kaynaklar" izni isterse ZArchiver için izin ver.

Bilgisayarda: ZIP'i aç, `EndlessDriving.zip.001` dosyasını 7-Zip ile aç ve APK'yı çıkar.

Gereksinim: Android 8.0 veya üstü. İnternet izni yoktur; oyun tamamen çevrimdışı çalışır.
